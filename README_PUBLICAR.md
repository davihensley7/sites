# Publicação no GitHub Pages — Davi Hensley

1. Crie um repositório **público** no GitHub (ex.: `meu-catalogo-web`).
2. Envie **os arquivos desta pasta**, não o ZIP e não a pasta `catalogo-fonte-privado`.
3. Confirme que `index.html` está na raiz do repositório.
4. Em **Settings → Pages**, selecione `Deploy from a branch`, branch `main`, pasta `/(root)`.
5. Depois da publicação, em **Settings → Pages**, ative `Enforce HTTPS` se aparecer.
6. Ative autenticação em dois fatores na sua conta do GitHub.

**ATENÇÃO:** O código do site publicado continua acessível no navegador. O catálogo
não contém backend nem segredos. Esta versão implementa CSP, links externos seguros,
aviso de direitos autorais e identificação visível do autor. Estes recursos reduzem
riscos e reforçam a autoria, mas não impedem cópia do código ou de capturas de tela.

Se o código original já foi publicado em um repositório público, removê-lo em um
commit novo não apaga a versão antiga do histórico público.

Código-fonte para edição: guarde separadamente o arquivo `catalogo-fonte-privado.zip`.
